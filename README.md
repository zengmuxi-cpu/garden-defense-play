# 花园保卫战 (Garden Defense)

这是一个使用 Godot 4 制作的塔防小游戏的可玩 Web 版本。

## 在线游玩

访问 [https://zengmuxi-cpu.github.io/garden-defense-play/](https://zengmuxi-cpu.github.io/garden-defense-play/) 即可在浏览器中游玩。

## 基本操作

- 点击一张卡片，然后点击草坪格子来种植植物
- 点击阳光来收集资源
- 右键取消选择

## 说明

本仓库仅包含编译后的 HTML5 Web 构建版本，通过 GitHub Pages 托管。游戏源代码不在此仓库中。
