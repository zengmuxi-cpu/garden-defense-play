# 《露珠守园人 Dewkeepers》 1.0

治愈系分路塔防：种下并合成植物、挑选园艺祝福，击退枯萎虫群，守护心树。

## 在线游玩

访问 [https://zengmuxi-cpu.github.io/garden-defense-play/](https://zengmuxi-cpu.github.io/garden-defense-play/) 即可在浏览器中游玩。

## 免费试玩版

这里提供的是免费试玩版：可以完整体验 3 关旅程，难度最高开放到「枯萎 I」（Blight I），其余内容在完整版中解锁。

## 基本操作

- 把卡片拖到花床格子上种植
- 同种同星级拖到一起可合成升星
- 每波结束后从三个园艺祝福里选一个

本仓库仅包含使用 Godot 4 导出的 HTML5 Web 构建版本（单线程导出），通过 GitHub Pages 托管。游戏源代码不在此仓库中。
